# 청라에너지 미납관리 대시보드

엑셀 파일을 업로드하면 미납/납부 현황을 보여주는 완전한 정적(static) 웹페이지입니다.
서버나 Google Apps Script 없이 `index.html` 파일 하나만 열면 브라우저 안에서 모든 계산이 이루어집니다.

> 이전 버전은 Google 스프레드시트와 Apps Script로 동작했지만, 이번 버전부터는
> 사용자가 직접 엑셀 파일을 업로드하는 방식으로 바뀌었습니다. 더 이상 구글 계정
> 연동이나 스프레드시트 공유 설정이 필요하지 않습니다.

## 사용 방법

1. `index.html` 파일을 더블클릭해서 브라우저로 엽니다 (인터넷 연결 필요 — 차트/엑셀 라이브러리를 CDN에서 불러옵니다).
2. 우측 상단 "엑셀 업로드" 버튼을 눌러 아래 4개 시트를 포함한 엑셀 파일(.xlsx)을 선택합니다.
3. 업로드가 끝나면 대시보드가 자동으로 채워지고, "연체수용가현황" / "월말기준미납(수납처리)" 버튼으로 서식이 적용된 엑셀 보고서를 바로 다운로드할 수 있습니다.
4. 다른 파일로 다시 보려면 "다시 업로드" 버튼을 눌러 새로고침한 뒤 새 파일을 업로드하면 됩니다.

## 업로드할 엑셀 파일의 시트 구성

한 워크북(xlsx) 안에 아래 4개 시트가 정확한 이름으로 모두 들어있어야 합니다.

- **전월_미납내역**: 고객명, 고객번호, 연체개월, 합계, (월별 청구금액 컬럼들…)
- **전월_납부이력**: 고객명, 고객번호, 납부일시, 납부금액
- **현재_미납내역**: 전월_미납내역과 동일한 컬럼 구성 (이번 달 기준)
- **현재_납부이력**: 전월_납부이력과 동일한 컬럼 구성 (이번 달 기준)

전월 시트는 "전월 대비 연체 현황 비교" 섹션(구간별 증감, 관리 필요 고객 목록)에 사용되고,
현재 시트는 대시보드 본문 전체(KPI, 차트, 고객 목록, 두 가지 엑셀 출력)에 사용됩니다.

월별 청구금액 컬럼은 `26.7월`, `26.6월`처럼 "YY.M월" 형식의 헤더를 자동으로 인식합니다.
날짜 컬럼(납부일시)은 엑셀의 날짜 형식 셀이면 그대로 인식됩니다.

## 동작 원리 (요약)

- **데이터 파싱**: 업로드된 파일을 [SheetJS](https://sheetjs.com/)로 읽어 시트별 2차원 배열로 변환합니다 (`XLSX.read`, `cellDates:true`).
- **연체/납부 상계(FIFO)**: 고객별로 모든 납부 기록을 합산한 뒤, 청구월 오래된 순서대로 차감해 잔여 연체금액·연체개월을 계산합니다.
- **엑셀 보고서 생성**: 예전에는 Google Apps Script가 서버에서 구글시트를 만들어 서식(병합·테두리·정렬·숫자서식)을 입힌 뒤 xlsx로 변환했지만, 지금은 서버가 없으므로 [ExcelJS](https://github.com/exceljs/exceljs)를 사용해 브라우저에서 동일한 서식을 직접 생성합니다.
- 모든 처리(엑셀 읽기 · 계산 · 엑셀 쓰기)는 브라우저 내에서만 이루어지며, 업로드한 데이터는 어디에도 저장되거나 전송되지 않습니다. 새로고침하면 다시 업로드해야 합니다.

## 외부 라이브러리 (CDN)

- Chart.js 4.5.1 — 차트
- SheetJS (xlsx) 0.18.5 — 엑셀 파일 읽기
- ExcelJS 4.4.0 — 서식이 적용된 엑셀 파일 생성/다운로드

인터넷이 연결되지 않은 환경에서 쓰려면, 위 세 라이브러리 파일을 내려받아
`index.html`과 같은 폴더에 두고 `<script src>` 경로만 로컬 파일 경로로 바꾸면 됩니다.

## 라이선스

내부 업무용 프로젝트입니다. 별도 명시가 없는 한 청라에너지 내부에서만 사용합니다.
