엑셀을 올리면 접수 현황과 이슈 감지 결과가 자동으로 갱신됩니다

데이터 기준일—
샘플 데이터 — 2025년 1월~2026년 9월 18일 가상 데이터입니다(9월은 진행 중인 달로 연출, 오늘을 9월 19일로 봄). 고객명은 가상 번호, 단지명은 지역명만 실제이고 이름은 지어낸 것입니다. 엑셀을 올리면 샘플은 지워집니다.
업로드된 데이터가 없습니다 민원 엑셀 파일을 올리거나 화면에 끌어다 놓으세요.
제목행에 접수일 · 키워드 열은 반드시 있어야 하며, 양식은 template/민원데이터_양식.xlsx를 참고하세요.
샘플은 2025년 1월~2026년 9월 18일 가상 데이터입니다. 실제 고객·단지 정보는 없습니다.
여기에 놓으면 업로드됩니다

고객명 분류 — 단지 / 개인

고객명 항목에 개인명과 단지명이 혼재되어 입력됩니다. 1회 분류 시 이후 자동 적용되며, 접수 건수 순으로 정렬되어 있어 상위 20~30건 지정으로 대부분 처리됩니다.

단지명 목록 파일(js/site-tokens.local.js)이 없어 브랜드명만 적힌 고객명은 자동 추정되지 않습니다. 사내에서 파일을 받아 js 폴더에 넣거나, 아래에서 직접 지정하세요.

분류 결과는 이슈 판정에 사용되지 않으며, 감지된 이슈의 단지별 내역 확인에만 사용됩니다. 미분류 상태로 두어도 집계는 정상 동작합니다.
표기가 상이한 단지(예: 청라크레이티브 / 크레이티브 아파트)는 대표명 항목에 동일 명칭을 입력하면 통합됩니다.
이름만으로 성격을 알 수 없는 수용가(예: ○○9차 → 프라자)는 유형을 직접 지정하십시오.
