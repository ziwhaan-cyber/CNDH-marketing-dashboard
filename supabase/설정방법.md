# 공유 저장소(Supabase) 설정 방법

대시보드는 이 설정을 마치기 전까지 지금처럼 **각자 PC 안에서만** 동작한다(로그인 없음).
`js/cloud-config.js`에 주소와 키를 넣는 순간부터 로그인 · 권한 · 자동 공유가 켜진다.
시연 주소(`?demo=1`)는 설정과 관계없이 로그인 없이 가상 데이터로 열린다.

## 1. 프로젝트 만들기 (한 번)
1. supabase.com → GitHub로 가입 → **New project**
2. 이름 `cndh-dashboard`, Region **Northeast Asia (Seoul)**, 요금제 Free
3. Database Password는 자동 생성값을 안전한 곳에 보관(대시보드 코드에는 쓰지 않음)

## 2. 표와 권한 규칙 만들기 (한 번)
- 왼쪽 **SQL Editor → New query** → `supabase/schema.sql` 내용을 통째로 붙여 넣고 **Run**
- 여러 번 실행해도 안전하다(규칙을 고친 뒤 다시 실행하면 최신으로 바뀐다)

## 3. 보안 설정 (한 번) — 꼭 할 것
- **Authentication → Sign In / Providers → Email**
  - `Allow new users to sign up` **끄기** (아무나 가입하지 못하게. 계정은 관리자만 만든다)
- **Authentication → URL Configuration**
  - Site URL: `https://cndh-marketing-dashboard.vercel.app`
  - (초대·비밀번호 재설정 메일의 링크가 이 주소로 돌아온다)

## 4. 계정 만들기 (사람이 늘 때마다)
- **Authentication → Users → Add user**
  - `Send invitation`: 직원이 메일 링크를 눌러 직접 비밀번호를 정한다(권장)
  - `Create new user`: 관리자가 임시 비밀번호를 정해 전달(Auto Confirm 체크)
- 새 계정은 자동으로 **조회자**가 된다. 담당자·관리자는 SQL Editor에서 역할을 바꾼다:

```sql
update public.profiles set role = 'arrears', name = '김연체'
where id = (select id from auth.users where email = '직원메일@회사.com');
```

| role | 화면 표시 | 할 수 있는 것 |
|---|---|---|
| `admin` | 관리자 | 전체 업로드 · 출력 · (SQL로) 역할 지정 |
| `arrears` | 연체 담당 | 연체 현황 · 미납관리 업로드, 미납안내문 PDF · 발송 |
| `voc` | 민원 담당 | 민원 업로드, 고객명 분류, AI 분석 실행 |
| `viewer` | 조회자 | 현황 · 연체 현황 · 민원통계 · 이슈 모니터링 조회만 |

## 5. 대시보드에 연결 (한 번)
- **Project Settings → API**에서 두 값을 복사해 `js/cloud-config.js`에 넣고 커밋 · 푸시
  - `Project URL` → `url`
  - `anon` `public` 키 → `anonKey`
- ★ **`service_role` 키는 절대 넣지 않는다.** 모든 규칙을 무시하는 관리자 키다.

## 무엇이 서버에 올라가나
| 자료 | 올리는 사람 | 올라가는 내용 |
|---|---|---|
| 연체 현황 | 연체 담당 | 개월별 개소 · 금액 합계 (원래 집계값) |
| 미납관리 요약 | 연체 담당 | 미납 건수 · 금액 · 3개월 이상 · 구간별 수 (고객별 내역은 안 올라감) |
| 민원 접수 기록 | 민원 담당 | 접수일 · 경로 · 키워드 · 지역 등. **고객명은 가명**(단지명은 그대로), **접수·처리내용은 안 올라감**(처리 여부만) |
| 이슈 모니터링 요약 · AI 분석 결과 | 민원 담당 | 이슈 판정 · AI 요약 문장 |

- 원본 엑셀, 고객명, 이메일, 접수내용 원문은 담당자 PC 밖으로 나가지 않는다.
- 미납관리 고객별 화면 · 미납안내문 생성은 원본이 필요하므로 연체 담당 PC에서만 동작한다.
- 누가 언제 올렸는지는 `upload_log` 표에 남고, 화면 오른쪽 위 이름에 마우스를 올리면 보인다.
- 로그아웃하면 그 PC에 받아 둔 사본도 지워진다.
