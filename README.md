# 청라에너지 마케팅 AI코파일럿

엑셀을 올리면 연체·미납·민원 현황을 한 화면에서 보여주는 정적 웹페이지. 서버 없이 `index.html`을 열면 동작하며, `main`에 푸시하면 Vercel에 자동 배포된다.

## 파일 구성
```
index.html                    화면 틀(HTML) — 스타일·스크립트는 아래 파일을 불러온다
css/dashboard.css             대시보드 본문 스타일
theme.css                     세 화면 공통 테마 (맨 아래 'v2 다듬기' 블록을 지우면 이전 모습)
js/nav.js                     페이지 전환 · 시연 모드 표시
js/heat-arrears.js            업로드 데이터 저장 · 열판매현황 · 연체 현황
js/household-voc.js           주택용 개발현황 · 민원통계/데이터
js/arrears-notice.js          연체 탭 전환 · 미납안내문(PDF) 생성
js/home.js                    현황(첫 화면) · AI 인사이트 · 시연 데이터
cheongna-overdue-dashboard/   미납관리 (고객관리(연체) → 미납관리 탭에 끼워 넣음)
  ai-insight.js               미납 AI 분석 — 집계만 AI에 보내 원인·리스크·우선 조치 정리
  sample-ai.js                시연 모드용 미납 AI 예시 결과
민원/                          이슈 모니터링 (고객관리(민원) → 이슈 모니터링 탭에 끼워 넣음, 자세한 내용은 민원/README.md)
```
스크립트는 ES 모듈이 아닌 일반 `<script>`로 순서대로 읽는다. `index.html`의 로드 순서를 바꾸지 말 것.

## AI 인사이트 (현황 화면)
- 민원(이슈 모니터링)·미납(미납관리)의 AI 분석 결과 중 **원인·리스크**만 두 칸으로 보여준다
- AI가 제안한 **조치**는 데일리 체크에 `AI 제안`으로 합친다 (같은 사안의 줄이 있으면 그 줄에 붙임)
- 두 화면 모두 숫자 계산·판정은 코드가 하고, AI는 해석만 한다. 고객명·고객번호는 AI에 보내지 않는다

## 데일리 체크 (현황 화면)
- 단계는 '연체 현황'과 같게: 단기 1~2개월 / 중기 3~5개월(공급정지 안내) / 장기 6개월 이상(법적조치 검토)
- `→` 버튼: 미납관리 고객 목록을 그 단계로 걸러 열거나, 이슈 모니터링의 해당 구역(이슈 감지·다발 단지·AI 분석)으로 이동
- 어제 있던 항목이 오늘 없어지면 맨 위에 '해결'로 표시 (그 영역 데이터가 오늘도 있을 때만)
- 미납 데이터가 하루 넘게 지나면 미납 항목 대신 '다시 올려주세요' 한 줄, 이때는 저장된 연체 현황 파일로 장기·중기를 보여준다
- 기준값: 미납 단계·금액 `cheongna-overdue-dashboard/index.html`의 `MINAP_RULES`, 민원 경과일 `민원/js/config.js`의 `UNRESOLVED_AGED_DAYS`

## 시연 모드
주소 끝에 `?demo=1`을 붙이면 모든 탭이 가상 데이터로 채워진다 (예: `https://…vercel.app/?demo=1`).
- 민원: `민원/js/sample.js` 샘플 + `sample-ai.js` AI 예시 / 미납관리: 보존된 샘플 생성 코드 / 연체 현황: 미납관리 샘플 요약에서 만듦
- 저장 이름 앞에 `demo_`를 붙여 실제로 올린 데이터와 섞이지 않는다. 헤더의 **종료**를 누르면 시연 데이터가 지워진다.
- AI 결과는 미리 작성한 예시이며 화면에 "샘플 예시 · 실제 AI 호출 아님"으로 표시된다.
