# 청라에너지 마케팅 AI코파일럿

엑셀을 올리면 연체·미납·민원 현황을 한 화면에서 보여주는 정적 웹페이지. 서버 없이 `index.html`을 열면 동작하며, `main`에 푸시하면 Vercel에 자동 배포된다.

## 파일 구성
```
index.html                    화면 틀(HTML) — 스타일·스크립트는 아래 파일을 불러온다
css/dashboard.css             대시보드 본문 스타일
theme.css                     세 화면 공통 테마 (맨 아래 'v2 다듬기' 블록을 지우면 이전 모습)
js/nav.js                     페이지 전환 · 시연 모드 표시 · 업로드 파일 이름 표시
js/heat-arrears.js            업로드 데이터 저장 · 열판매현황 · 연체 현황
js/household-voc.js           주택용 개발현황 · 민원통계/데이터
js/arrears-notice.js          연체 탭 전환 · 미납안내문(PDF) 생성
js/home.js                    현황(첫 화면) · AI 인사이트 · 데일리 체크 · 시연 데이터
js/tab-highlights.js          연체·민원 탭의 '핵심 한 줄'과 표 안 강조
cheongna-overdue-dashboard/   미납관리 (고객관리(연체) → 미납관리 탭에 끼워 넣음) — 별도 작성자의 화면, 원본 그대로 사용
민원/                          이슈 모니터링 (고객관리(민원) → 이슈 모니터링 탭에 끼워 넣음, 자세한 내용은 민원/README.md)
```
스크립트는 ES 모듈이 아닌 일반 `<script>`로 순서대로 읽는다. `index.html`의 로드 순서를 바꾸지 말 것.

## AI 인사이트 (현황 화면)
- 이슈 모니터링의 AI 분석 결과 중 **원인·리스크**를 보여준다
- AI가 제안한 **조치**는 데일리 체크에 `AI 제안`으로 합친다 (같은 사안의 줄이 있으면 그 줄에 붙임)
- 숫자 계산·판정은 코드가 하고, AI는 해석만 한다. 고객명은 AI에 보내지 않는다
- 미납관리 화면이 요약에 AI 결과(`ai`)를 넘겨주면 미납 칸이 자동으로 함께 나온다 (지금은 없음)

## 데일리 체크 (현황 화면)
- 미납: 미납관리 화면이 저장하는 요약(3개월 이상 · 1,000만원 이상 · 연체 1개월)을 읽는다
- 연체 현황: 미납 요약이 없거나 하루가 지났으면 저장된 연체 현황 파일로 장기(6개월 이상)·중기(3~5개월)를 보여준다
- 민원: 이슈 모니터링 요약(뜬 이슈 · 다발 단지 · 오래된 미처리 등). `→` 버튼은 이슈 모니터링의 해당 구역으로 이동
- 어제 있던 항목이 오늘 없어지면 맨 위에 '해결'로 표시 (그 영역 데이터가 오늘도 있을 때만)
- 민원 경과일 기준은 `민원/js/config.js`의 `UNRESOLVED_AGED_DAYS`

## 시연 모드
주소 끝에 `?demo=1`을 붙이면 가상 데이터로 채워진다 (예: `https://cndh-marketing-dashboard.vercel.app/?demo=1`).
- 민원: `민원/js/sample.js` 샘플 + `sample-ai.js` AI 예시
- 미납관리: 파일은 원본 그대로 두고, 대시보드가 그 화면의 '엑셀 업로드'로 가상 고객 142명 샘플을 올린다 (`js/home.js` demoFillMinap)
  미납관리는 요약을 항상 원래 이름(minap_summary)에 저장하므로, 시연 값은 demo_ 이름으로 옮기고 원래 값은 되돌려 둔다
- 연체 현황: 미납 샘플 요약에서 만들어 두 화면의 개소 수·금액이 맞음
- 저장 이름 앞에 `demo_`를 붙여 실제로 올린 데이터와 섞이지 않는다. 헤더의 **종료**를 누르면 시연 데이터가 지워진다.
- AI 결과는 미리 작성한 예시이며 화면에 "샘플 예시 · 실제 AI 호출 아님"으로 표시된다.
